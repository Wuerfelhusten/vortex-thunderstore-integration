# Changelog

## 1.1.0

- Added modpack installation into an existing or new profile.
- Fixed modpack dependency conflicts and recognition of installed dependencies.
- Fixed missing mod names and identification data, with automatic repair for affected Thunderstore entries.
- Improved native update checks and download reliability.
- Fixed Valheim mod asset placement.
- Improved cancellation and safeguards when switching profiles.

Previously misplaced mod files require reinstallation. Existing staging folders and Nexus mods are left untouched.

## 1.0.0

Initial release with Thunderstore browsing, mod installation, metadata, and supported-game mappings.
